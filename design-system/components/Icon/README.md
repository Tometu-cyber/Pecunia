# Icon

Les pictogrammes au trait du portail : contour arrondi de 1,75 px, dessinés sur une grille de 24 px, dans l'esprit des SF Symbols.

**Noms disponibles :** `home`, `grid`, `search`, `user`, `plus`, `settings`, `chevron`, `calendar`, `bell`, `alert`, `check`, `chart`, `euro`, `clock`, `updown`, `more`, `edit`, `copy`, `trash`, `sort`, `x`, `back`, `filter`, `card`, `coins`, `swap`, `pin`, `trend`, et un par app : `finances`, `sport`, `alternance`, `alimentation`, `notes`.

**Props :** `name`, `size` (22 par défaut), `strokeWidth`, `label` (si l'icône est seule et porte un sens).

**Règles :**
- La couleur suit le texte (`currentColor`).
- Tailles : 18 px dans la barre latérale, 24 px dans la barre d'onglets, 22 px dans les boutons.
- Pour un nouveau pictogramme, garder la même épaisseur et les bouts arrondis. Lucide est la bibliothèque la plus proche si le set grandit.
